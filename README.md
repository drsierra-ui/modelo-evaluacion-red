# Modelo de Evaluación de Recursos Educativos Digitales — MIERED

Sitio académico desarrollado para la Maestría en Recursos Digitales Aplicados a la Educación de la Universidad de Cartagena.

## Versión 3.0

La versión incorpora trazabilidad explícita frente a la rúbrica de la actividad, dimensiones justificadas, metodología de aplicación, escala, ponderaciones, reglas de cálculo, lista de verificación y navegación responsive.

## Publicación

El proyecto es compatible con GitHub Pages. `index.html` debe permanecer en la raíz del repositorio.
